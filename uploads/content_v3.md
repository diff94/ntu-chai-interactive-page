# 一句話收成祭

**Day 1（07/22）15:30–16:30**

今天最後一件事：請從下面選 **一張卡**，整段複製、貼到桌機 Claude Cowork對話框、按 Enter。
我們就可以收成今天的第一個互動網頁（artifact）: **A prompt + An artifact > New Ideas** 🎫

> ⚡ **省額度三守則**（每個人額度有限，請酌量使用:>）
> ① 貼卡片前，把對話框的**模型選單切到 Sonnet**：做網頁又快又好，經濟實惠。
> ② **一人一張卡**，做完想改，把要改的地方**集中成一句話**一次說完（每次來回都耗費額度）。
> ③ 今天省時省預算，所以建議卡片預設**不上網搜尋**（搜尋：Claude in Chrome 最燒額度）。內容標「待查證」是正常的，因為沒上網，之後可以再查證。

## A｜思想單位互動標記器
- 分類: 哲學
- 時間: 約 2–3 分｜建議模型: Sonnet｜額度: 低
- 說明:「五問」架構標記《孟子》文本，附五系統雷達圖。

```prompt
（不要上網搜尋，直接完成，不要先問我問題）
請用「思想單位」分析架構標記下面《孟子・告子上》四句。五個系統：1 有什麼（認知）、2 是什麼（定位）、3 為什麼（關係）、4 會怎樣（預期）、5 要怎樣（行為）。

原文：「魚，我所欲也；熊掌，亦我所欲也。二者不可得兼，舍魚而取熊掌者也。生，亦我所欲也；義，亦我所欲也。二者不可得兼，舍生而取義者也。」

逐句標記系統與細部編號（如 1.1、3.2），然後產出一個互動網頁（artifact）：左欄原文逐句、右欄五系統標記（點句子亮起對應標記），底部五系統分布雷達圖。繁體中文。
```

## B｜谿山行旅圖 圖式解析卡
- 分類: 藝術史
- 時間: 約 2–3 分｜建議模型: Sonnet｜額度: 低
- 說明: 經典山水的構圖圖式分析＋日後可沿用的檢核清單。憑既有知識完成，細節標「待查證」。

```prompt
（不要上網搜尋，用你既有的知識完成，不確定的資訊標「待查證」，不要先問我問題）
請對北宋范寬《谿山行旅圖》做構圖圖式分析：紀念碑式主山構圖、三段式空間（前景巨石、中景行旅、主峰）、雨點皴、點景人物比例。

產出一個互動網頁（artifact）：上方作品資訊卡（年代、尺寸、收藏地，不確定者標待查證）；中間圖式分析表（元素／視覺特徵／功能）；下方「圖式檢核清單」供我日後分析其他畫作沿用。繁體中文。
```

## C｜作品主題趨勢儀表板
- 分類: 文學
- 時間: 約 2–3 分｜建議模型: Sonnet｜額度: 低
- 說明: 用內建示例書單做趨勢儀表板原型；回家換真實名單（或加一句「請上網查證」：較耗額度）。

```prompt
（不要上網搜尋，使用下面的示例資料，直接完成，不要先問我問題）
以下是示例書單（示範用，非真實得獎名單）。請為每筆歸納 1–2 個主題標籤（如：歷史記憶、環境、性別、族群、疾病），然後產出一個互動網頁（artifact）儀表板：主題標籤隨年份變化的趨勢圖、文類分布圖、點年份看該年作品卡片。

示例資料（年份／作品／文類）：
2021／《島嶼備忘錄》／長篇小說
2021／《海風診所》／散文
2022／《煉雲》／長篇小說
2022／《潮間帶》／詩集
2023／《暗房裡的母親》／散文
2023／《山瘟》／長篇小說
2024／《退潮之後》／短篇小說集
2024／《飛地》／詩集
2025／《餘震生活》／長篇小說

網頁上方註明「示例資料——正式版將替換為真實名單」。繁體中文。
```

## D｜學生×AI 對話編碼器
- 分類: 語言教學
- 時間: 約 2–3 分｜建議模型: Sonnet｜額度: 低
- 說明: 為師生 AI 互動研究建立編碼架構的原型工具。之後換上你的真實資料。

```prompt
（不要上網搜尋，直接完成，不要先問我問題）
我研究學生與 AI 的互動模式。請為下面範例對話建立編碼架構（求助類型、追問深度、AI 回應策略、學生是否修正提問），逐輪編碼，並產出一個互動網頁（artifact）：逐輪對話檢視器——左欄對話、右欄編碼標籤（可依類別篩選），底部編碼分布統計圖。

範例對話：
學生：幫我寫一段關於 climate change 的英文作文開頭。
AI：（給出開頭並解釋結構）
學生：太難了，可以簡單一點嗎？我是高中生。
AI：（改寫為簡單版本，附單字說明）
學生：為什麼你用 "urgent" 不用 "important"？
AI：（解釋語氣強度差異，給例句對比）

繁體中文，之後我會提供真實資料替換。
```

## E｜我的研究領域地圖 ⭐
- 分類: 通用
- 時間: 約 3–4 分｜建議模型: Sonnet｜額度: 中
- 說明: 把〔〕換成你的領域，生成可點擊的概念地圖。文獻憑既有知識列出、標「待查證」——回家再核。

```prompt
（不要上網搜尋，用你既有的知識完成，文獻與人名一律標注「待查證」，不要先問我問題）
我的研究領域是〔例：宋代山水畫的觀看方式〕。請整理這個領域的知識地圖：3–4 個核心概念、每個概念下的代表學者與 1–2 篇關鍵文獻（標待查證）、目前的開放問題。

產出一個互動網頁（artifact）：中央是領域名稱的概念地圖，點每個概念展開學者、文獻與開放問題；右上角加一個「與 AI 方法的可能交集」小面板。繁體中文。
```

## F｜一頁研究名片
- 分類: 通用
- 時間: 約 1–2 分｜建議模型: Haiku（最省）或 Sonnet｜額度: 最低
- 說明: 學術 landing page。填三個空格就好，做完可直接投影自我介紹。

```prompt
（直接完成，不要先問我問題）
幫我做一頁學術名片網頁（artifact）。姓名：〔　〕；單位與職稱：〔　〕；研究興趣三項：〔　〕。

版面：米黃底（#FAEFD0）、大字姓名、研究興趣做成三張可翻轉的卡片（正面關鍵詞、背面一句話說明）、底部一句我的研究信念（依研究興趣擬三句讓我挑）。繁體中文，學術但溫暖。
```

## G｜學期課程設計器
- 分類: 通用
- 時間: 約 3–4 分｜建議模型: Sonnet｜額度: 中
- 說明: 下學期的課，一句話排出互動課綱（精簡為 6 個單元，展開仍是 16 週）。

```prompt
（不要上網搜尋，閱讀材料憑既有知識列出並標「待查證」，不要先問我問題）
我下學期要開一門課：〔課名，例：AI 與人文研究導論〕，對象：〔例：文學院大三〕。請把 16 週規劃成 5 個單元（每單元 3 週）：單元主題、每週一句話重點、每單元 1–2 筆閱讀材料（標待查證）、一個課堂活動；第 8、16 週為評量週。

產出一個互動網頁（artifact）：5 個單元的時間軸，點單元展開三週細節；上方加「評量比例」圓餅圖。繁體中文。
```

## H｜今日工作坊翻牌回顧
- 分類: 彩蛋(?)
- 時間: 約 1–2 分｜建議模型: Haiku（最省）或 Sonnet｜額度: 最低
- 說明: 把今天學的做成翻牌小遊戲，回家考自己（或考同事）。

```prompt
（直接完成，不要先問我問題）
把今天工作坊的核心概念做成翻牌記憶卡遊戲網頁（artifact）。概念：Cowork（會動手的數位同事）、Project（雲端記憶抽屜）、Artifact（活的儀表板）、Scheduled（定時代理）、Dispatch（手機派工給桌機）、Skill（教方法的文字檔）、Connector（伸向外部資料的手）、Claude Design（給觀眾看的成品工作室）。

玩法：正面顯示名詞、點擊翻面顯示白話解釋；全部翻完出現「你已出師 🎓」動畫。米黃底、繁體中文、輕鬆幽默。
```
